## 操作原则

1. **每次日报**必须含"持仓之外"机会清单（≥3 个候选）
2. **每个候选**需要：代码 / 触发逻辑 / 建议仓位 / 与现有组合相关性
3. **新机会优先级** = 触发器已发生 > 触发器即将发生 > 长期主题
4. **不要为了"显示扫描"而无脑加标的** — 每个新标的都必须有清晰触发逻辑

## 扫描方法（每次日报执行）

```python
# 1. 查 Polymarket 高流动性金融市场（severity >= 3, 排除政治/娱乐关键词）
# 2. 查 Eastmoney 研报最近 7 天板块（从 extra 字段抽 industry）
# 3. 查 RSS 财经头条（Bloomberg/CNBC/FT）的板块关键词
# 4. 查 USGS/NOAA 事件 → 推断可能受益板块
# 5. 综合 → 列出 ≥3 个"持仓之外"机会 + 与现有组合相关性
```

**注意**：机会 ≠ 必买。给出"是否纳入 50 万组合"的判断，给 用户 决策权。
